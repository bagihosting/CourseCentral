# CourseCentral - Platform Kursus Online Next.js

Ini adalah proyek starter kaya fitur yang dibangun di Firebase Studio, menggunakan tumpukan teknologi modern untuk membuat platform e-learning yang kuat dan dapat diskalakan.

## Tumpukan Teknologi

-   **Framework**: Next.js 15 (dengan App Router)
-   **Bahasa**: TypeScript
-   **UI**: React, ShadCN UI
-   **Styling**: Tailwind CSS
-   **AI**: Google Gemini & Genkit
-   **Database**: MySQL
-   **Deployment**: Docker, Nginx, PM2

## Fitur Utama

-   Manajemen Pengguna & Peran (Admin, Instruktur, Pro, Member)
-   Manajemen Kursus & Kurikulum Lengkap
-   Sistem Afiliasi dengan Komisi & Penarikan Dana
-   Fitur-fitur AI untuk Pembuatan Konten (Deskripsi, Thumbnail, SEO, dll.)
-   Manajemen API Token yang Aman
-   Dasbor Admin & Instruktur yang Komprehensif
-   Skrip Instalasi & Deployment Otomatis
