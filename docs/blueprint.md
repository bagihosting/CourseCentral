# **App Name**: CourseCentral

## Core Features:

- Premium Member Dashboard: Dashboard view for premium members with membership duration (1-12 months).
- Admin Control Panel: Admin panel to manage user accounts and course content.
- Course Catalog: Course catalog browsing and search.
- Course Progress: Course progress tracking.
- Downloadable Content: Downloadable course materials.
- AI Course Suggestions: AI-powered tool suggesting courses tailored to user skills.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for a sophisticated and trustworthy feel.
- Background color: Light gray (#F5F5F5) to provide a clean and modern backdrop.
- Accent color: Teal (#009688) to highlight important elements and calls to action.
- Body and headline font: 'Inter' sans-serif for clear and accessible typography.
- Use a set of minimalist, professional icons to represent different features and course categories.
- Clean, card-based design to allow information to be shown with clear relationships between the various parts of each screen.
